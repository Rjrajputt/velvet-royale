# Velvet Royale

A mobile-first virtual-currency casino arcade prototype built with Node.js + Express + SQLite.

Features:
- Dark purple / gold casino aesthetic
- Touch-friendly landscape UI
- Server-authoritative mini game logic
- VC wallet system with demo-only purchase flow
- Daily bonus, leaderboard, Teen Patti-style showdown, raffle game
- No real-money payouts, no real financial system, and no actual payment rails

## Run locally

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

## Notes

This project is a polished prototype for research and development. It intentionally uses a virtual-currency model only and keeps all purchase and withdrawal flows in demo mode.
